# درس پنجم: async و await دقیقاً چطور کار می‌کنن

تا اینجا چند تا مثال عملی دیدیم و فهمیدیم که با ماژول `asyncio` می‌شه چند کار رو هم‌زمان جلو برد. ولی شاید هنوز برات سؤال باشه که پشت صحنه دقیقاً چی اتفاق می‌افته؟ این دو کلمهٔ جادویی یعنی `async` و `await` دقیقاً چه نقشی دارن؟ بیا با یه لحن خودمونی بریم سراغشون.

---

## معنی async چیه؟

وقتی جلوی یه تابع کلمهٔ `async` قرار می‌دی، در واقع داری به پایتون می‌گی:

> «هی، این تابع قراره یه کار زمان‌بر انجام بده. لطفاً بذارش تو صف کارای غیرهم‌زمان!»

کلمهٔ `async` باعث می‌شه اون تابع به یه **coroutine** تبدیل بشه. مفهوم coroutine یعنی تابعی که می‌تونه وسط اجرا متوقف بشه، منتظر بمونه، و بعد دوباره از همون‌جا ادامه بده. اینطوری برنامه می‌تونه چند تا کار رو با هم مدیریت کنه.

یه مثال ساده:

```python
import asyncio

async def say_hello():
    print("Hello")
    await asyncio.sleep(1)
    print("Goodbye")

asyncio.run(say_hello())
```

اینجا وقتی برنامه به عبارت `await asyncio.sleep(1)` می‌رسه، تابع موقتاً متوقف می‌شه. اما این توقف کل برنامه رو نمی‌خوابونه! فقط همین coroutine می‌گه: «من یه ثانیه منتظرم»، و در این فاصله، بقیهٔ کارها می‌تونن اجرا بشن.

---

## معنی await چیه؟

کلمهٔ `await` در واقع یعنی: «صبر کن تا این کار تموم بشه، ولی در این مدت بی‌کار نمون.»

یه مثال دم‌دستی:

```python
import asyncio

async def boil_water():
    print("Boiling water...")
    await asyncio.sleep(2)
    print("Water boiled!")

async def brew_tea():
    print("Brewing tea...")
    await asyncio.sleep(3)
    print("Tea brewed!")

async def main():
    await asyncio.gather(boil_water(), brew_tea())
    print("All tasks done!")

asyncio.run(main())
```

در این مثال، جوشوندن آب و دم کردن چای هم‌زمان شروع می‌شن. یکی دو ثانیه طول می‌کشه، اون یکی سه ثانیه. در نهایت وقتی هر دو کار تموم شدن، پیام آخر چاپ می‌شه. هیچ‌کدوم جلوی اون یکی رو نمی‌گیره.

به زبان ساده‌تر، کلمهٔ `await` یعنی: «این کار طول می‌کشه، ولی در این فاصله برو سراغ بقیهٔ کارها!»

---

## تفاوت coroutine با تابع معمولی

توابع معمولی از بالا تا پایین اجرا می‌شن و نمی‌تونن وسط راه متوقف شن. اما coroutineها فرق دارن؛ می‌تونن وسط اجرا متوقف شن، یه کاری رو صبر کنن، و بعد دوباره ادامه بدن.

یه مثال ساده:

```python
async def greet():
    print("Hello World")

result = greet()
print(result)
```

در اینجا خروجی متغیر `result` یه **coroutine object** هست، نه نتیجهٔ واقعی اجرای تابع. یعنی هنوز اجرا نشده! برای اینکه اجرا بشه باید از `await greet()` استفاده کنیم یا با `asyncio.run(greet())` راه بندازیمش.

---

## ماجرای پشت صحنهٔ await

وقتی از کلمهٔ `await` استفاده می‌کنی، پایتون یه جورایی می‌گه: «باشه، من فعلاً این coroutine رو متوقف می‌کنم تا نتیجه‌اش آماده بشه. در همین فاصله می‌رم ببینم کار دیگه‌ای هست یا نه.»

اینجا نقش یه چیزی به اسم **event loop** خیلی پررنگه. بعداً مفصل‌تر در موردش صحبت می‌کنیم. فعلاً فقط بدون که event loop اون مغز متفکر پشت ماجراست که coroutineها رو نوبتی اجرا می‌کنه.

می‌تونی این‌طوری تصورش کنی:

> وقتی به عبارت `await asyncio.sleep(2)` می‌رسی، یعنی دو ثانیه صبر کن ولی در این دو ثانیه اگه کار دیگه‌ای هست، برو اون کارا رو انجام بده.

---

## نکتهٔ خیلی مهم

فقط داخل تابعی که با `async` تعریف شده می‌تونی از `await` استفاده کنی. در تابع‌های معمولی این کار ممکن نیست. برای همین معمولاً یه تابع اصلی (مثلاً `main`) می‌نویسن که async باشه و بعد با `asyncio.run(main())` کل برنامه رو اجرا می‌کنن.

---

## جمع‌بندی درس

* دستور `async` یعنی تابع می‌تونه وسط اجرا متوقف بشه و بعداً ادامه بده.
* دستور `await` یعنی منتظر بمون، ولی در این فاصله کارای دیگه رو انجام بده.
* یه event loop هست که مدیریت می‌کنه کِی کدوم coroutine اجرا بشه.

---

در درس بعدی قراره بریم سراغ همین event loop و ببینیم پایتون چطور بین coroutineها جابه‌جا می‌شه و نظم اجرا رو حفظ می‌کنه.
