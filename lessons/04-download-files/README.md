# دانلود هم‌زمان چند فایل با asyncio

تا اینجا یاد گرفتیم چطور با async و await توابع غیرهم‌زمان بنویسیم و با مفهوم تسک (Task) و حلقهٔ رویداد (Event Loop) آشنا شدیم. حالا وقتشه یه مثال واقعی‌تر بزنیم تا ببینیم این چیزایی که یاد گرفتیم، تو عمل چطوری کار می‌کنن. توی این درس می‌خوایم چند تا فایل رو به‌صورت هم‌زمان دانلود کنیم (البته به شکل شبیه‌سازی‌شده).

هدف اینه که بفهمیم چطوری می‌شه چند کار رو با هم پیش برد و زمان اجرای برنامه رو به حداقل رسوند.

---

## ایدهٔ اصلی

فرض کن سه تا فایل داری که هرکدوم چند ثانیه طول می‌کشه تا دانلود بشن. اگه بخوای دونه‌دونه دانلودشون کنی، باید صبر کنی تا یکی تموم شه و بعدی شروع بشه. ولی اگه همه رو هم‌زمان بندازی تو صف، زمان کل به اندازهٔ طولانی‌ترین دانلود می‌شه، نه مجموعشون. این دقیقاً جاییه که asyncio به دادمون می‌رسه.

---

## شبیه‌سازی دانلود

قراره دانلود واقعی نکنیم. فقط با asyncio.sleep() زمان انتظار رو شبیه‌سازی می‌کنیم تا ببینیم برنامه چطوری چند کار رو هم‌زمان انجام می‌ده.

import asyncio
import random
import time

async def download(name: str):
    delay = random.uniform(1, 3)
    print(f"⬇️ {name} started (takes {delay:.1f}s)...")
    await asyncio.sleep(delay)
    print(f"✅ {name} finished!")

async def main():
    start = time.perf_counter()
    await asyncio.gather(
        download("File A"),
        download("File B"),
        download("File C"),
    )
    end = time.perf_counter()
    print(f"🕒 Done in {end - start:.2f} seconds")

asyncio.run(main())

---

## توضیح قدم‌به‌قدم

۱. اول از همه کتابخونه‌های asyncio`، `random و time رو ایمپورت کردیم.
۲. تابع download یه coroutine هست که با async def تعریف شده. هر بار که اجراش می‌کنیم:

* یه زمان تصادفی بین ۱ تا ۳ ثانیه انتخاب می‌کنه تا نشون بده دانلود چقدر طول می‌کشه.
* بعد پیام شروع چاپ می‌شه.
* await asyncio.sleep(delay) باعث می‌شه تابع منتظر بمونه، ولی بقیهٔ کارها متوقف نشن.
* در آخر هم پیام پایان چاپ می‌شه.
  ۳. توی main از asyncio.gather() استفاده کردیم تا هر سه دانلود با هم شروع بشن.
  ۴. با time.perf_counter() مدت اجرای کل برنامه رو اندازه گرفتیم تا تفاوت هم‌زمانی رو ببینیم.

## خروجی نمونه

خروجی چیزی شبیه این می‌شه:

⬇️ File A started (takes 2.1s)...
⬇️ File B started (takes 1.3s)...
⬇️ File C started (takes 2.7s)...
✅ File B finished!
✅ File A finished!
✅ File C finished!
🕒 Done in 2.72 seconds

می‌بینی؟ هر سه دانلود با هم شروع شدن و بعد از حدود ۲٫۷ ثانیه همگی تموم شدن. اگه برنامه به‌صورت معمولی (بدون async) نوشته می‌شد، زمان کل بیشتر از ۶ ثانیه می‌شد.

## مقایسه با حالت معمولی

بیایم همین کار رو بدون async انجام بدیم تا فرقش رو بهتر ببینیم:

import time
import random

def download(name: str):
    delay = random.uniform(1, 3)
    print(f"⬇️ {name} started (takes {delay:.1f}s)...")
    time.sleep(delay)
    print(f"✅ {name} finished!")

start = time.perf_counter()

download("File A")
download("File B")
download("File C")

end = time.perf_counter()
print(f"🕒 Done in {end - start:.2f} seconds")

اینجا چون time.sleep() کل برنامه رو متوقف می‌کنه، مجموع زمان اجرا چیزی حدود ۶ تا ۸ ثانیه می‌شه. یعنی هر دانلود منتظر تموم شدن قبلیه.

---

## نقش gather در asyncio

تابع asyncio.gather() یه ابزار خیلی مهمه که چند تا coroutine رو هم‌زمان اجرا می‌کنه و وقتی همشون تموم شدن، نتیجه رو برمی‌گردونه.

مثلاً اگه بنویسیم:

results = await asyncio.gather(task1(), task2(), task3())

اینجا سه تا coroutine با هم شروع می‌شن، و وقتی همشون تموم شدن، نتایجشون توی results برمی‌گرده.

## تمرین برای تو

می‌تونی همین کد بالا رو یه کم پیشرفته‌تر کنی:

* در آخر نتایج رو چاپ کن.
* یه مورد خاص بذار که عمداً خطا بده و ببین gather() چطوری با خطاها برخورد می‌کنه.
